# **App Name**: DevLaunch Portfolio

## Core Features:

- Dynamic Content Management: Empower the portfolio owner to easily update all textual and media content for sections like projects, about me, and skills through an intuitive interface.
- Project Showcase Display: Present individual portfolio projects with dedicated cards including images, brief descriptions, and links to live demos or repositories, mirroring a clean, feature-focused layout.
- About Me & Skills Section: A dedicated section to clearly articulate the portfolio owner's professional journey, skills, and experience in a structured and easily consumable format.
- Contact & Inquiry Form: Integrate a functional contact form to allow prospective employers or clients to send messages directly to the portfolio owner, akin to lead generation on a landing page.
- Responsive Design Adaptability: Ensure the portfolio page is fully responsive, maintaining visual integrity and functionality across all device sizes from desktops to mobile phones, emulating the template's flexible nature.
- AI Project Brief Generator: A generative AI tool for the portfolio owner to create concise, engaging project summaries and achievement bullet points from raw notes, streamlining content creation for diverse audiences.

## Style Guidelines:

- The visual scheme embraces a light, fresh palette. The primary color is a rich, forest green (#2ED259), symbolizing growth and innovation, suitable for call-to-action buttons and key interactive elements.
- The background color is a very subtle, pale green (#E8F2EB), providing an airy and clean canvas that keeps the focus on the content and provides a calming base, derived from the primary's hue.
- An accent color of bright, energetic lime green (#66F51A) is used for highlights and interactive elements that require particular attention, creating dynamic contrast while remaining analogous to the primary color.
- Headlines and body text utilize 'Poppins' (sans-serif) for its precise, contemporary, and geometric feel, providing a clean and readable presentation similar to the template's strong, modern typeface.
- Icons should be clean, modern, and vector-based (e.g., SVG) to ensure scalability and sharpness, consistent with the minimalist yet effective iconography observed in the provided template.
- A clear, prominent hero section dominates the initial view, similar to the template, followed by distinct sections for projects, skills, and contact information. The layout emphasizes strong visual hierarchy and centered content.
- Subtle hover effects and smooth transitions should be applied to interactive elements like buttons and navigation links, offering a polished user experience without distracting from the portfolio's content.
