# DevLaunch Portfolio

DevLaunch Portfolio is a modern, high-performance portfolio template for software developers. It features a bold red aesthetic, responsive design, and an AI-powered project brief generator.

## Key Features

- **AI Project Brief Generator**: Transform raw project notes into professional summaries.
- **Dynamic Content Showcase**: Beautiful project cards and skill categories.
- **Responsive Layout**: Seamless experience across mobile, tablet, and desktop.
- **Modern Tech Stack**: Built with Next.js 15, Tailwind CSS, Lucide Icons, and Framer Motion (subtle interactions).

## Theming

- **Primary**: Red (#FF0000)
- **Background**: Pale Red (#FFF5F5)
- **Accent**: Bright Red (#FF3300)
- **Font**: Poppins (Sans-serif)
